ISSUE 01 / 中二怪

中二怪

31 岁。在美国上学，刚毕业做新闻。

兔子洞一样跳到做脱口秀，在笑果做导演。主导了《脱口秀大会 2》等节目。

2023 年在职业高峰期辞职，开始 gap。

在微博/即刻发内容，做内容十年。

目前的职业：专栏作家（小报童：不是办法）/ 运营线上社群 / 带旅行团 / 做即兴喜剧 / 香港保险销售

“在金钱之外，我看到的是更奇妙的、让我更感到振奋的一个叙事的变化” 《金钱游戏》

大家一定有过那种「擅长的东西自己并不是非常喜欢」的经历，这就是我和金钱的关系 —— 但到这里也就足够了。

在金钱之外，我看到的是更奇妙的、让我更感到振奋的一个叙事的变化：

横向来说，过去常常几百个人才能托举一个人（皇家、高官、巨贾、将军），你生下来如果是贱命一条，那么大概率就是要托举和服务一个位高权重的人，根本不可能实现什么所谓的自我价值；

纵向来说，过去很多人只是家庭的血脉传送者（工具人），如果自己没展示出什么出息和才能，就十几二十岁赶紧生个孩子，重新扔一次基因骰子，看看有没有可能是下一代让自家的祖坟冒青烟。只要二三十岁没冒尖，人的主要使命就退化给家庭，主打一个把香火传下去，你不再有属于自己的机会，不要再想有的没的了；

而如今每个人的可能性、天花板都被打开了。你可以自己托举自己、支持自己；二三十岁还没发现自己的特长能力，你可以慢慢等、慢慢探索。互联网和发达的基建让世界变得更平，不论出身环境，再贱的命、再惨的开局都不必做他人附庸，每个人都终于有机会选择和成为自己。

而且，人的寿命还延长了。走出浅滩，多出来的时间，都是你的了。

所以，这才是奇迹真正发生的时刻——历史上第一次，在通关金钱第一关之后，你还能有大几十年的时间，没有压力、没有捆绑、没有必须完成的任务，够闲、够放松，没有任何压力，不在金钱上紧张。山海辽阔，前方自由。

初步的财富自由，是一个充满现代性的赎身过程。被突然降生在这个陌生的人间，谁没有一身的债要还、累世的功课要做、弱鸡要赶、疑惑要解、恩情要报答，也都得花点心思证明自己值得这个世界供养给你的一切。于是你用心地钻研、勤恳地工作、俭朴地生活，最后终于烧掉了自己的卖身契。这当然不是故事的结束，只是开始，没有人甘心在这里躺平认怂的，爽文才刚写了一个开头，真正好玩的还在后面呢！把债还清、小试牛刀、杀掉了第一个难缠的小怪，你人生的第二条成长曲线，那个「成为自己」的英雄之旅，在这时才终于开启。

在那些迎着风跳跃着向前走、放松且充满希望的魔法时刻，我曾知道自己永远与过去不同了。在那些时刻，我清楚地知道并想分享，一个人一定要给自己很多很多时间和很多很多安全感，你的神性才会被养育和迸发。第一人称的电影到这里才开始来到高潮，一定要及时赶到啊。

金钱不是你的终极游戏，养生不是，家庭也不是。你有你自己的游戏，那是你内心核能般的生命力终于找到时机爆发的时刻。正因如此，你知道在那之前每一个关卡都有它的意义，都将在更深处养育、引导和解放你。

“独处能力就是一个人的核心力量。” 《亲密关系的游戏》

2.3 当一个人没有核心力量的时候，他就会借助其他器官、肌肉、骨骼的力量去代偿，从而动作变形、扭曲身体。当他无法独处，他就会使用愤怒、依赖、控制、上瘾、索取，作为「弱」的代偿。

2.7 一个很好的练习耐受孤独的方法，就是寻找和培养一个真正的爱好。「爱好」也是一个从来没有出现在我们教育系统里的词汇，所以很可惜，很多上一辈人都是没有爱好的，这也成为他们尤其容易感到孤独、无法独处、依赖子孙的原因。

2.7.1 很多人没有爱好，只有消遣，消遣是一个封闭的系统，只会导致熵增，因此会越消遣越虚无。抽烟、打麻将、嗑瓜子、看电视、旅游、逛街、刷手机，都是消遣。

而爱好是一个开放系统——随着练习会越做越好（进步肉眼可见，满足情绪价值）、有输入（学习的过程）和输出（总结经验、教别人、参加比赛、认识新朋友）的渠道，能有可积累的价值（有进步和展示空间、掌握技巧后可以脱离模板进行集结创作、积攒长期非功利性的友谊、做好了可以分享经验或教学赚钱、最起码可以为身边的人提供价值）。

“写小报童的两年，我从 ENFP 变成了 INTJ。” 《不能原地踏步》

除了还是相信直觉，其他的全变了，写作对我形成了高达 75% 的洗脑。若你想真正学会一个技能或深耕某个领域，我的建议是试着写一个系列的零基础攻略、教程出来——不需要都做完、都研究透彻再写攻略，就是在你自己还理解得很浅的时候就开始写，有了不懂的现查，逻辑上产生断裂的也现去思考，这是非常高效的学习方式，也是费曼学习法的核心理念。我常引用木心说「写作是秉烛夜游」，是一样的道理，写的过程就是深度探索和学习，写完分享还可造福众人，再点亮一盏烛火，岂不妙哉。

能写作的人，和只会看或者说的人，天生对一个领域的探究和思考就是两个维度。你要表达、且要对自己表达的内容负全责，这让整件事都变得郑重。郑重地做事情，就会把一件事做得更深、更好，这也是借了某种神性的力量。

ISSUE 01 / JOSCHA BACH

Joscha
Bach

52 岁。德国认知科学家、AI 研究者。

主要研究 AGI、认知架构、心智表征，以及情感与动机的计算模型。

曾在 MIT Media Lab 与 Harvard Program for Evolutionary Dynamics 从事研究。

“现实并不是直接呈现给我们的，我们从现实中得到的唯一东西就是现象。” World Model / Self Model

我们所体验到的这些颜色和声音并不以这种形式存在于物理学中。我们所体验的都是一些模式，这些模式是大脑使我们能够感知的。而这个感知世界中的“人”也并不存在。

神经元并不知道体验是什么样的感觉，所以它们创建了一个模型，模拟出如果有一个“人”能够体验这些事物，那会是什么样子。

这个模型就是我们所认为的“自我”：ego is a model。这个自我是意识的一部分，它是一种工具，用来帮助我们理解所感知的世界。通过这种方式，“自我”与世界相连，它是意识的一种创造。

换句话说，我们的意识是一个创造者，它利用神经元的基质创建了一个完全虚拟的世界，而我们的大脑就是这个虚拟世界的引擎。

如果我们进行冥想，我们可以完全调节自己与宇宙之间的接口，甚至关闭过去学习到的模板，这样我们就能更多地意识到真实的情况。如果你进入极深的冥想状态，你甚至可以关闭自我模型。

自我模型并不是我们的意识本身，而是大脑给自己编织的一种故事，帮助我们理解自己在世界中的位置。这个故事是高层次学习的基础。

“至于我们是谁，我认为我们是计算系统。” AI / Mind as Computation

现实的本质是什么？我认为宇宙通过在我们的系统接口上产生模式来减少不确定性。信息是由微小可辨别的差异构成的，而计算是产生这些模式的必要且充分条件。

那么我们能知道什么呢？信息可以被编码成感知、概念、模拟、世界观、文化等。至于我们是谁，我认为我们是计算系统，这些系统编码信息、存储信息、处理信息，并以非常特定的方式解释这些信息。

我们可以通过构建这些计算模型，来了解这一类我们称之为“心智”的计算系统。

我认为在观察和建模之间做出选择并不是一个好的划分，因为这会让你变成一个非常不完整的人。分离观察和建模、分离科学和艺术，是我们在思维者的教育中应该避免的。我们希望培养那些会反思、能成长为完整人的人。这种能力是互补的。

我们发现，许多伟大的科学家也同时是画家和音乐家，拥有广泛的兴趣。将人们从这些兴趣中割离开来，以便在极其狭窄的学术或工业就业市场中更具竞争力，我认为这也是从文化中剔除了一些可能对推动进步至关重要的东西，尤其是对发展新范式的推动。

想象一下，如果你能构建能够共鸣的系统，系统能够像你深刻共鸣的人一样，与你自己的心智产生共鸣。当你与另一个人有感知上的共鸣时，你会实时在对方的心智中构建反馈回路，你们在心灵上是共振的。它创造了你无法单独拥有的心理状态。通过与他人合并，扩展了你的能力。

通常情况下，人们的心理状态差异太大，很难让一个大群体在高度清晰的心理状态下彼此共鸣，所以常常会失去很多。

“情感可以被看作是认知系统的一种配置。” 情感与动机

当你成为一个成年人时，我认为，最重要的部分是你要掌控自己的情绪。你要意识到你自己的情绪是由你自己的大脑、你自己的身体产生的。它们的存在是为了服务于你。你存在的意义不是服务于你的情绪。

但我在一生中学到的是，我所有的痛苦都是不清醒的结果。宇宙不会给我客观的好或坏的东西。宇宙给了我一堆电脉冲，我的大脑通过创建一个模拟世界来理解它们。而那个模拟世界中的价态完全是内在的。

当你可以选择自己的情绪时，你不一定想要拥有最快乐的情绪，你想要拥有最合适、最有帮助的情绪。如果世界是危险的，我想要感受到恐惧，以便能够对它做出适当的反应；我不想只是感觉良好或感到安全。

情感或作用是系统的配置，它不是系统中的一个参数。我们有几个维度，例如我们当前所处的唤起状态、我们的固执程度、我们的选择阈值、注意力是向内还是向外，等等。这些东西加在一起就形成了我们认知的调节。

简单来说，动机决定你要做什么，情感决定你怎么做。

“大海是个好东西。”关于做播客
“把重要的事，放进最高优先级。” 关于选择

真正重要的事，不只需要目标、方法和意志。它更需要其他安排让路，成为日程里无需反复谈判的第一优先级。

困难通常不是做不到，而是没有把优先级排到足够高。选择一件事，也意味着明确舍弃另外一些事。

“工作几年后，给自己一次 self-caring gap year。” 关于暂停

主动离开惯性一年，不是消遣：补基础技能，研究真正关心的问题，做出具体作品；也重新检查身体、关系、财务和生活方式。

重点不是逃离工作，而是用一段完整时间恢复感受力，再决定下一段生活要把力气放在哪里。
