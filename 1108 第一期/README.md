# 多样生活的人类样本（第一期）

这是可直接发布到 GitHub Pages 的静态站点包。

## 文件结构

```text
index.html
reads/
  joscha-bach.html
  zhonger-weibo.html
```

## 最短发布步骤

1. 在 GitHub 新建一个 Public repository。
2. 进入仓库，选择 `Add file` → `Upload files`。
3. 打开本文件夹，把里面的全部内容拖进上传区并提交。
4. 进入 `Settings` → `Pages`。
5. `Source` 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/(root)`，保存。
6. 等待 GitHub 显示站点地址，打开即可。

发布后，入口页、三张人物图片和两份长文阅读器都由 GitHub Pages 提供；作品导航中的播客、微博、小报童、Lex Fridman 与 CCC 链接仍需要联网访问。
